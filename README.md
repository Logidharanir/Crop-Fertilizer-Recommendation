# 🌱 AgriAI — 100% Machine Learning Crop & Fertilizer Recommendation System

This package is a genuine end-to-end machine-learning project, not just a Streamlit interface.

## ML pipeline

### Crop Recommendation
Dataset → train/test split → StandardScaler → RandomForestClassifier → evaluation → saved model → Streamlit prediction.

### Fertilizer Recommendation
Dataset → train/test split → ColumnTransformer → StandardScaler + OneHotEncoder → RandomForestClassifier → evaluation → saved model → Streamlit prediction.

## Files

- `app.py` — Streamlit application
- `train_models.py` — complete ML training code
- `data/Crop_recommendation.csv` — crop dataset
- `data/Fertilizer_Prediction.csv` — fertilizer dataset
- `models/` — trained ML model files
- `reports/` — test-set metrics
- `requirements.txt` — dependencies
- `README.md` — project guide

## Run

Recommended: Python 3.12.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python train_models.py
streamlit run app.py
```

`train_models.py` is included so you can retrain the models yourself. The ZIP already contains trained model artifacts, so you can run the app directly after installing requirements.

## Important

ML accuracy is evaluated on a held-out test set. No ML project can honestly guarantee 100% prediction accuracy. “100% ML” here means the recommendations are generated by trained machine-learning models with preprocessing and evaluation, rather than hard-coded rules.
